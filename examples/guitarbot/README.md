# Exemple : Guitarbot (professeur généré par le Builder Bot)

Professeur de guitare acoustique **généré en simulation** à partir de l'entretien de `entretien-simule.md`, avec le modèle du Builder Bot. Il n'a pas été testé avec de vrais apprenants : c'est un exemple de format, à relire avant tout usage.

- `PROMPT.md` : le prompt (mêmes sections que les 5 bots, domaine `guitare`).
- `skills/guitarbot-role/SKILL.md` et `skills/guitarbot-demarrage/SKILL.md`.
- `compte-rendu-exemple.md` : un compte rendu fictif au format attendu par le Bot Profil.
- Nom d'import : « Grok Bot Academy - Guitarbot ».
