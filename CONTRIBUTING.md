# Contribuer

Les améliorations sont les bienvenues : prompts, format du profil, nouveaux profs, scripts d'installation.

1. Ouvre une issue pour décrire l'idée ou le problème.
2. Pour un changement, fais un fork puis une pull request courte et ciblée.
3. Ne mets jamais de données personnelles, de clés ou de vrais profils d'apprenants dans une contribution.
4. Pour un nouveau prof, utilise le Builder Bot (`bots/builder-bot/`) ou copie un fichier de `prompts/`, et garde les mêmes règles : lire le profil, séance structurée, compte rendu obligatoire, aucune invention.
